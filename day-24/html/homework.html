Task 1 — Create a Barrel File

Create a folder named utils containing: add.js, multiply.js, and constants.js.

Create an index.js barrel file that:

  • Uses named re-exports for add and multiply
  • Uses export * for constants

Import everything from a single line in app.js.

View Solution 

// utils/index.js

export { add } from "./add.js";
export { multiply } from "./multiply.js";

export * from "./constants.js";

// app.js

import {
  add,
  multiply,
  PI,
  APP_NAME
} from "./utils/index.js";

console.log(add(2, 3));
console.log(multiply(4, 5));
console.log(PI);
console.log(APP_NAME);

// Output:
// 5
// 20
// 3.14159
// MyApp

Task 2 — Dynamic import()

Create a module named feature.js exporting a function showFeature().

In main.js, dynamically load the module when a button is clicked.

Verify in the Network tab that the module is loaded only when needed.

View Solution 

// feature.js

export function showFeature() {
  console.log("Feature loaded!");
}

// main.js

const btn =
  document.querySelector("#load-feature");

btn.addEventListener(
  "click",
  async () => {
    const module =
      await import("./feature.js");

    module.showFeature();
  }
);

// Output:
// Feature loaded!

Task 3 — Circular Dependency

Create two modules: a.js and b.js.

Make each module import a value from the other module.

Observe the circular dependency issue caused by top-level execution.

Refactor the code to eliminate the circular dependency.

View Solution 

// a.js

import { valueB } from "./b.js";

export const valueA =
  valueB + 1;

// b.js

import { valueA } from "./a.js";

export const valueB =
  valueA + 1;

// Circular dependency occurs because
// both modules need values that are
// not fully initialized yet.

// Fix:
// Move dependent logic into functions
// instead of running at module load time.
