Task 3 — Dynamic import()

Create a heavy.js module that exports a compute() function.

Use await import() to load the module only when needed.

Call the exported function after loading.

View Solution 

export function compute() {
  return "computed!";
}

async function loadAndRun() {
  const module =
    await import("./heavy.js");

  console.log(
    module.compute()
  );
}

loadAndRun();

// computed!

Task 2 — Default + Named Export

Create a module named Button.js.

Export a default Button() function.

Also export a named object: ButtonStyles.

Import both using a single import statement.

View Solution 

export default function Button(label) {
  return `Button: ${label}`;
}

export const ButtonStyles = {
  primary: "btn-primary",
  secondary: "btn-secondary"
};

import Button, {
  ButtonStyles
} from "./Button.js";

console.log(Button("Submit"));
console.log(ButtonStyles.primary);
console.log(ButtonStyles.secondary);

// Button: Submit
// btn-primary
// btn-secondary

Bonus — Singleton Cache Module

Create a shared cache.js module exporting a single Map.

Create:

  • userService.js
  • productService.js

Both modules should write to the same cache instance.

Verify that all data is visible from main.js.

View Solution 

const cache = new Map();

export default cache;

// userService.js
cache.set("u1", {
  id: "u1",
  name: "Alice"
});

// productService.js
cache.set("p1", {
  id: "p1",
  name: "Laptop"
});

console.log(cache);

// Map(2)
