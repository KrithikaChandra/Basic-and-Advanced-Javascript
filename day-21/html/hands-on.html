Task 1 — Prove Shallow Clone Bug

Create: const orig = { name: "Priya", addr: { city: "Jaipur" } }

Make a shallow copy with spread: const copy = { ...orig }

Mutate: copy.addr.city = "Mumbai"

Log: orig.addr.city and observe the bug.

Now use: structuredClone(orig) and confirm the original object remains untouched.

View Solution 

const orig = {
    name: "Priya",
    addr: {
        city: "Jaipur"
    }
};

const copy = { ...orig };

copy.addr.city = "Mumbai";

console.log(orig.addr.city); // Mumbai

// The bug:
// Spread creates only a shallow copy.
// Nested objects are still shared references.

// Using structuredClone
const copy1 = structuredClone(orig);

copy1.addr.city = "Chennai";

console.log(orig.addr.city); // Mumbai

// Original object remains untouched

Task 2 — Immutable Nested Update

Take this state:

const state = { user: { name: "Priya", prefs: { theme: "light", lang: "en" } } }

Produce a NEW state with: prefs.theme = "dark"

Use spread syntax without mutating the original object.

Verify: state.user.prefs.theme is still "light".

View Solution 

const state = {
    user: {
        name: "Priya",
        prefs: {
            theme: "light",
            lang: "en"
        }
    }
};

const newState = {
    ...state,
    user: {
        ...state.user,
        prefs: {
            ...state.user.prefs,
            theme: "dark"
        }
    }
};

console.log(newState.user.prefs.theme); // dark

console.log(state.user.prefs.theme); // light

Task 3 — Update One Item in an Array

Take:

const tasks = [ { id: 1, title: "Learn JS", done: false }, { id: 2, title: "Build app", done: false } ]

Write a function: toggleDone(tasks, id)

Return a NEW array with the matching task’s done value flipped.

Use: .map() and spread syntax.

Verify originals never mutate.

View Solution 

const tasks = [
    { id: 1, title: "Learn JS", done: false },
    { id: 2, title: "Build app", done: false }
];

function toggleDone(tasks, id) {

    const newTasks = tasks.map((t) =>
        t.id === id
            ? { ...t, done: !t.done }
            : t
    );

    return newTasks;
}

console.log(toggleDone(tasks, 1));

console.log(toggleDone(tasks, 2));

console.log(tasks);

Bonus — Safe Deep Read

Take this partial API response:

const data = { user: { name: "Priya", profile: { city: null } } }

Write a single expression that safely reads: data.user.profile.city

Fall back to: "Unknown" if anything is null or undefined.

Also safely read: data.user.profile.bio?.length ?? 0

Try again with: const data = {} and confirm it does not crash.

View Solution 

const data = {
    user: {
        name: "Priya",
        profile: {
            city: null
        }
    }
};

// const data = {};

const data1 =
    data?.user?.profile?.city ?? "Unknown";

console.log(data1); // Unknown

const data2 =
    data?.user?.profile?.bio?.length ?? 0;

console.log(data2); // 0
