Task 1 — Pure or Impure?

Given the following functions, identify whether each is pure or impure.

  • (a, b) => a + b
  • () => Date.now()
  • (arr) => arr.sort()
  • (arr) => [...arr].sort()
  • (x) => { console.log(x); return x; }

For impure functions, explain why they are impure.

View Solution 

// (a, b) => a + b
// Pure

// () => Date.now()
// Impure — returns different values each call

// (arr) => arr.sort()
// Impure — mutates the original array

// (arr) => [...arr].sort()
// Pure — creates and sorts a copy

// (x) => { console.log(x); return x; }
// Impure — has a side effect (console output)

Task 2 — Pipe from Scratch

Implement pipe(...fns).

The returned function should pass a value through each function from left to right.

Create: addOne, square, and negate.

Test with: pipe(addOne, square, negate)(5)

Expected output: -36

View Solution 

function pipe(...fns) {
  return input =>
    fns.reduce((acc, fn) => fn(acc), input);
}

const addOne = x => x + 1;
const square = x => x * x;
const negate = x => -x;

const result = pipe(
  addOne,
  square,
  negate
);

console.log(result(5));
// -36

Task 3 — Curry It

Write a curried function: volume(l)(w)(h)

It should return: l * w * h.

Pre-apply: l = 5 and w = 3.

Finally call it with: h = 2.

Verify the result is: 30.

View Solution 

const volume =
  l => w => h =>
    l * w * h;

const lengthOf5 = volume(5);

const lengthOf5width3 =
  lengthOf5(3);

console.log(
  lengthOf5width3(2)
);

// 30

Bonus — Real Pipeline

Given an array of users:

  • Filter users with age ≥ 18
  • Capitalize names
  • Sort by age descending
  • Return only the names

Use pipe and small pure functions only.

View Solution 

const users = [
  { name: "priya", age: 25 },
  { name: "aarav", age: 17 },
  { name: "riya", age: 30 }
];

function pipe(...fns) {
  return input =>
    fns.reduce(
      (acc, fn) => fn(acc),
      input
    );
}

const adults = users =>
  users.filter(
    user => user.age >= 18
  );

const capitalizeNames = users =>
  users.map(user => ({
    ...user,
    name:
      user.name[0].toUpperCase() +
      user.name.slice(1)
  }));

const sortByAgeDesc = users =>
  [...users].sort(
    (a, b) => b.age - a.age
  );

const namesOnly = users =>
  users.map(user => user.name);

const getNames = pipe(
  adults,
  capitalizeNames,
  sortByAgeDesc,
  namesOnly
);

console.log(
  getNames(users)
);

// ["Riya", "Priya"]
